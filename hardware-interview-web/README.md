# 硬件面试题库网页

一个离线可打开的硬件面试题库单页网页，目前整理 277 道题，按大厂/小厂侧重点、技术方向、难度和关键词筛选。

## 文件

- `index.html`：页面结构
- `styles.css`：响应式界面样式
- `app.js`：题库数据和筛选逻辑
- `assets/hardware-banner.png`：本地生成的电路板视觉图

直接双击 `index.html` 即可在浏览器中打开。
