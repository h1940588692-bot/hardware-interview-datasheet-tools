# 硬件面试和数据手册工具

这个仓库整理了两个本地可直接打开的硬件学习网页工具。

## 工具一：硬件面试题库

位置：`hardware-interview-web/`

入口：`hardware-interview-web/index.html`

也可以下载 `硬件面试题库网页-分享版.zip`，解压后打开里面的 `index.html`。

面试网页依赖同目录下的 `app.js`、`styles.css` 和 `assets/` 图片资源，不能只单独下载 HTML。

## 工具二：数据手册阅读和翻译工具

位置：`datasheet-translator/`

入口：`datasheet-translator/index.html`

也可以下载 `数据手册阅读翻译工具-分享版.zip`，解压后打开里面的 `index.html`。

这个工具可以帮助阅读英文 datasheet，整理关键词、风险边界、设计参数和验证步骤。默认重点阅读和术语辅助功能可以离线使用；PDF 解析和 AI 翻译功能可能需要联网。

## 快速使用

1. 点击 GitHub 页面右上角 `Code`。
2. 选择 `Download ZIP`。
3. 解压后分别打开对应目录里的 `index.html`。
