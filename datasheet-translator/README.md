# 数据手册阅读和翻译工具

这是一个本地可直接打开的 Datasheet 阅读辅助网页。

## 文件

- `index.html`：工具入口，双击即可用浏览器打开。

## 功能

- 粘贴或导入英文数据手册文本。
- 自动标注常见硬件/芯片数据手册关键词。
- 按风险边界、设计参数、验证步骤整理阅读重点。
- 可切换到术语辅助模式。
- AI 专业翻译模式需要使用者自己填写兼容 OpenAI Chat Completions 的接口地址和 API Key。

## 使用方式

1. 下载本目录。
2. 双击 `index.html`。
3. 粘贴英文 datasheet 内容，或导入文本/PDF 文件。

## 注意

默认的重点阅读和术语辅助功能可以离线使用。PDF 解析和 AI 翻译功能可能需要联网。
